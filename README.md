## 一键使用方法 (制作任意新壁纸)

### 方式一：最简双击运行（推荐）
1. 将任意你喜欢的图片（`.jpg` / `.png` / `.webp`）丢进 `laptop/input/` 文件夹；
2. 双击运行 `laptop/run.bat`；
3. 脚本会自动调用你的 **RTX 4060 GPU** 完成：
   - 自动消除杂波与 16:10 几何居中校正；
   - Real-ESRGAN 神经网络 4x 超分（消除生硬黑边）；
   - Lanczos 抗锯齿下采样至标准 16:10 4K（3840 × 2400）；
   - 自动组装为包含 50% 优雅慢速落樱、库洛魔法星尘与 2.5D 视差的完整 Web 壁纸工程；
4. 运行完毕后，会自动在浏览器中弹窗全屏预览！

### 方式二：命令行灵活微调
打开 PowerShell 或 CMD，进入 `laptop/` 目录执行：
```powershell
# 处理指定单张图片
python pipeline.py -i input/my_pic.jpg

# 自定义分辨率（例如适配拯救者 2.5K 屏幕 2560x1600）
python pipeline.py -i input/my_pic.jpg -W 2560 -H 1600

# 切换为微量胶片柔光风格 (film)
python pipeline.py -i input/my_pic.jpg --style film
```

## 核心方法论与避坑经验复盘

在将静态动漫原画制作成高品质笔记本壁纸的过程中，沉淀了以下四条关键经验：

### 1. 屏幕画幅与比例避坑（杜绝左右挤压变形）
* **常见陷阱**：很多网络图片是 16:9（1.778）或 4:3（1.333），而现代笔记本屏幕（拯救者、ThinkBook、ROG、MacBook 等）普遍采用 **16:10 (1.600)** 黄金比例。如果强行拉伸填充，画面会被硬生生挤压 **11.9%**，导致人物脸颊变窄、五官失真。
* **解决方案**：在超分前通过算法做**严格的几何对称居中裁切**（如过宽则仅切除左右边缘无关紧要的天空背景），确保角色本体长宽比 1:1 绝对不变。

### 2. 避免前期双线性插值“虚胖模糊”
* **常见陷阱**：很多标称“4K”的原图（如 2867×1792）实际上是早年低清截图被低级算法强行放大后的产物，线条自带羽化毛边。如果直接对其二次放大，模型会把“模糊”当成特征继续放大。
* **解决方案**：流水线内置识别逻辑，对于过大的低质图像，先用 Lanczos 降采样收拢至原生致密基底，再让卷积神经网络重新生成真正的高频线稿。

### 3. 模型选型：消灭物体边界生硬的“刀刻黑色描边”
* **常见陷阱**：通用的 `realesrgan-x4plus-anime` 会对所有高频边缘施加极强的高对比加深，导致手绘赛璐珞动画的下巴、发丝、肩膀产生类似“黑色记号笔描边”的生硬轮廓，像剪纸贴画。
* **解决方案**：选用专门针对动画视频帧调优的 **`realesr-animevideov3` 模型**，并强制开启 **TTA (Test-Time Augmentation) 8重旋转多角度加权推断**。线条自然圆润平滑，同时完美保留眼睛高光与睫毛超清细节。

### 4. 粒子动态美学：落樱速度减半放缓
* **常见陷阱**：默认粒子物理速度往往偏快，导致花瓣像直升机旋翼般频繁自转穿梭，容易造成视觉疲劳并抢占桌面注意力。
* **解决方案**：将花瓣下落速度、叶面 3D 翻转周期与正弦微风摆动周期**全面减半放缓 50%**，搭配库洛牌魔法星尘和鼠标点击扩散效果，营造出宁静悠然的梦幻氛围。

## 如何设为笔记本动态壁纸？

### 1. Wallpaper Engine (小红车)
1. 打开 Wallpaper Engine，点击左下角 **“壁纸编辑器”** -> **“从文件打开”**；
2. 选中 `sample_sakura_wallpaper/index.html`（或 `output/` 中任意生成的壁纸目录下的 `index.html`）；
3. 软件会自动读取 `project.json`，在桌面右侧属性栏即可自由拖动滑块实时调节花瓣数量、微风风速与魔法星尘！

### 2. Lively Wallpaper (免费开源神器)
1. 打开 Lively Wallpaper 软件；
2. 直接将任意壁纸工程下的 `index.html` 拖入软件窗口，点击确认即可。

### 3. 极简浏览器屏保
- 随时双击 `index.html`，按键盘 `F11` 进入沉浸式无边框全屏模式。
