# 动态壁纸生成与环境配色工具（默认 16:10 4K）

本工具从输入图片生成独立网页壁纸工程，包括居中裁切、GPU 超分、目标尺寸缩放、环境自动配色和交互特效。路径由脚本所在目录确定，可整体迁移工具包。

> [!TIP]
> 工具包内置 Windows 版 Real-ESRGAN Vulkan 程序与模型；生成工程仍需要 **Python 3、Pillow，以及能够运行内置 Vulkan 超分工具的显卡和驱动环境**。本工具不会自动安装依赖或驱动。打开已生成网页不需要运行 Python。

## 一键使用方法 (制作任意新壁纸)

### 方式一：最简双击运行（推荐）
1. 将图片（`.jpg` / `.jpeg` / `.png` / `.webp` / `.bmp`）放进 `input/` 文件夹；
2. 双击运行 `laptop/run.bat`；
3. 脚本会递归读取支持的图片文件，并执行：
   - 将透明区域合成到白底，按目标宽高比居中裁切；
   - 使用内置 Real-ESRGAN 模型做 4x 超分，默认启用 TTA；
   - Lanczos 缩放到目标尺寸，默认 3840 × 2400；
   - 根据最终底图的环境色与明暗生成特效配色，自动组装慢速花瓣、星尘与 2.5D 视差壁纸工程；
4. 首张工程生成后，会打开浏览器预览；需要全屏时按 `F11` 或使用网页面板按钮，不会自动进入全屏。

工程默认写入 `output/<输入文件名>_4k_wallpaper/`。`_4k_wallpaper` 后缀为兼容现有命名保留，自定义尺寸时以底图和标题中的实际分辨率为准；标题、描述、面板、README 和录制文件名按各自工程名称生成。样例保留小樱身份，现有 `output/12` 保留原目录。

### 方式二：命令行灵活微调
打开 PowerShell 或 CMD，进入 `laptop/` 目录执行：
```powershell
# 处理指定单张图片
python pipeline.py -i input/my_pic.jpg

# 自定义分辨率（例如适配拯救者 2.5K 屏幕 2560x1600）
python pipeline.py -i input/my_pic.jpg -W 2560 -H 1600

# 指定输出根目录，并关闭浏览器预览
python pipeline.py -i input/my_pic.jpg -o output/custom --no-browser

# 替换已有工程的 bg.png 后，仅刷新自动特效配色，不运行超分或打开浏览器
python pipeline.py --refresh-theme output/12

# 批处理转发相同参数；有空格的路径需加引号
.\run.bat --refresh-theme "output\12"
```

宽度和高度必须为正整数。`--model` 可选择内置模型，`--no-tta` 可关闭 TTA。`--style natural` 为默认行为；`--style film` 仅保留兼容入口，目前明确报错，不生成或修改底图。批处理结束会暂停，并保留 Python 的退出码；需要自动化调用时可直接使用 Python 命令。

### 自动特效配色与手动调整

- 生成时分析最终底图的缩略图，外圈四分之一区域的权重为中央的三倍，优先参考周围环境色。该方法不识别人物或场景；人物靠近边缘时仍可能影响取色。
- 花瓣、常规及点击星尘、背景柔光共享一个主色。黑白或低饱和背景使用淡蓝色 `#b8d9f2`；柔光随背景亮度调节到原强度的 35%～100%，并继续受星尘强度滑块控制。花瓣形状、运动和控制面板配色保持原样。
- 右上角控制面板中的“特效主色”提供原生选色器和可直接点击、选中文字、输入及粘贴的 R/G/B 数值框，两种入口双向同步。RGB 仅接受 0–255 十进制整数，合法输入立即联动全部画面特效并保存；逐位输入产生的合法中间值也会生效。
- 编辑时允许清空或暂时输入无效数值，文字和光标不会被立即回写；回车或离开输入框后恢复最近已应用的值并提示。例如从空白输入 256 时，2、25 先后生效，256 无效，结束编辑后恢复为 25。原生选色弹窗无法编辑数值时，可使用面板内的 RGB 输入框。
- “恢复自动配色”使用生成时写入 HTML 的颜色，移除当前壁纸的手动覆盖，并同步选色器、RGB 数值及清除输入错误。
- 手动选择保存在当前浏览器或壁纸宿主的本地存储中，按网页路径区分；相同路径重新生成或刷新配色后，手动选择继续优先生效，点击恢复即可使用新的自动配色。移动工程、切换浏览器或壁纸软件后，不保证继承选择。
- 存储不可用时，选色仍可使用，面板提示“仅本次生效”；无效的保存记录会被忽略。网页不进行实时取色，替换底图后需要执行刷新命令并重新打开网页。
- 刷新命令只更新已有 `index.html` 的配色数据块，保留底图、其他网页内容、脚本及工程配置。底图缺失、不可读取或网页缺少唯一的 `effect-theme` 数据块时明确报错。该命令不会升级 RGB 控件；旧工程需要同步新版网页和脚本，并保留各自工程名称与自动配色数据。
- 配色刷新不会更新工程名称及分辨率信息；若替换底图时改变了尺寸，需要重新生成工程或同步修改元信息。
- 网页默认花瓣 75、风速 1.0x、星尘 1.2x、镜头呼吸 1.0x、视差 1.2x；Wallpaper Engine 的花瓣、风速和星尘属性会同步到网页控件。手动特效选色使用网页面板，宿主的 `schemecolor` 不参与特效配色。
- 面板可按目标 60fps 录制六秒 WebM 片段；实际帧率和录制 API 兼容性需实测，不保证首尾无缝循环。

## 图像处理流程

以下描述来自当前实现，不代表对所有图片都能获得相同的画质改善。

### 1. 目标比例与居中裁切

使用目标宽度除以高度确定裁切比例。过宽时裁左右，过高时裁上下；比例差小于 0.01 时跳过预裁切，最后仍按目标尺寸缩放。裁切不识别主体，边缘人物可能被裁掉。

### 2. 超分前的尺寸预处理

裁切后宽度大于 2000 像素时，先使用 Lanczos 缩小到宽度 1920，再调用超分工具。这是尺寸规则，不会检测图片是否模糊或经过低质量放大。

### 3. 超分与目标尺寸

默认使用 `realesr-animevideov3`，可选择 `realesrgan-x4plus-anime` 或 `realesrgan-x4plus`。工具以 4x 缩放运行，TTA 可关闭；超分结果再通过 Lanczos 缩放到目标尺寸。

### 4. 网页特效

底图与花瓣、星尘在同一画布中绘制，保留慢速花瓣运动、镜头呼吸及视差。颜色来自生成时的环境分析或用户手动覆盖；动画使用浏览器帧回调，实际帧率取决于运行环境。

## 如何设为笔记本动态壁纸？

### 1. Wallpaper Engine (小红车)

使用 `sample_sakura_wallpaper/index.html` 或生成工程中的 `index.html` 作为网页项目入口导入，保留同目录的底图、脚本与 `project.json`。配置提供花瓣数量、风速和星尘强度；其他参数、RGB 数值输入和手动特效选色使用网页控制面板。

### 2. Lively Wallpaper

将壁纸工程中的 `index.html` 添加为网页壁纸，保留同目录资源。

### 3. 极简浏览器屏保
- 随时双击 `index.html`，按键盘 `F11` 进入沉浸式无边框全屏模式。
