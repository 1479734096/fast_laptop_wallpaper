# 木之本樱 & 小可 - 3840×2400 交互式动态壁纸

本目录为独立网页壁纸工程，使用本目录内的 [bg.png](bg.png)，背景分辨率为 3840 × 2400。

## 核心特性

1. **本地底图与画幅适配**：
   - 读取工程内的 `bg.png`，按实际底图比例居中铺满窗口；镜头呼吸和视差会放大、偏移底图，不能保证逐像素显示完整画幅。
2. **多层花瓣与 3D 翻转**：
   - 远景、中景、前景花瓣以不同尺寸和速度飘落，保留樱花轮廓、微风摆动、自旋及翻转。
3. **环境配色星尘闪烁系统**：
   - 四角星芒与柔光浮尘缓缓向上升腾，呼吸明灭；花瓣、星尘和背景柔光共享从底图提取的环境主色，深色背景降低柔光叠加强度。
4. **生动点击互动**：
   - 点击画面可散落花瓣与星尘；点击控制面板或齿轮按钮不会触发画面特效。
5. **2.5D 镜头呼吸与空间视差**：
   - 镜头随正弦波呼吸起伏，随鼠标或触摸移动产生多层视差；设备允许方向事件时，也可响应倾斜。
6. **动态控制面板与一键录制**：
   - 面板可调花瓣数、风速、星尘强度、镜头呼吸和视差灵敏度，并提供全屏切换。默认花瓣 75、风速 1.0x、星尘 1.2x、呼吸 1.0x、视差 1.2x；宿主属性变更会同步到网页控件。
   - 使用浏览器录制 API 导出六秒 WebM 片段，目标帧率 60fps，不保证实际帧率或首尾无缝衔接。下载文件名来自当前工程名称。
7. **自动配色与手动覆盖**：
   - 在生成工程时分析底图，外圈四分之一区域权重为中央的三倍，优先参考周围环境；低饱和背景使用淡蓝色。这是颜色统计，不进行人物分割或场景识别。
   - 面板的“特效主色”提供原生选色器和 R/G/B 数值框，两种入口双向同步；可直接点击、选中文字、输入或粘贴 0–255 十进制整数，合法输入立即联动花瓣、常规及点击星尘和柔光并保存。原生弹窗无法编辑数值时，可使用网页内 RGB 输入框。
   - 编辑时保留空值、无效数值及光标位置，不应用无效值；回车或离开输入框后恢复最近已应用的值并提示。合法中间值也会生效，例如从空白输入 256 时，2、25 先后生效，最终越界会恢复为 25。
   - “恢复自动配色”移除手动覆盖，使用 HTML 内保存的自动颜色，同步选色器和 RGB 数值，并清除输入错误。
   - 手动颜色按网页路径保存在当前浏览器或壁纸宿主中；相同路径重新生成后继续保留，恢复自动配色即可启用新的取色结果。换路径或换宿主后不保证继承；存储不可用时提示“仅本次生效”，选色仍可使用。
   - 替换 `bg.png` 后，网页不会自行重新取色。在工具包根目录执行 `python pipeline.py --refresh-theme "工程目录"`，或 `run.bat --refresh-theme "工程目录"`，再重新打开网页。该命令只更新 HTML 的配色数据，不运行超分、不改底图，也不升级 RGB 控件；旧工程需同步新版网页和脚本，并保留各自工程名称与自动配色数据。
   - 若替换图片同时改变了尺寸，标题和说明中的原始工程尺寸不会由配色刷新命令修改；需要重新生成工程或同步调整这些信息。

## 使用与安装指南

### 1. 浏览器直接体验
- 直接双击打开本目录下的 [index.html](index.html)；
- 按 `F11` 或点击控制台中的 **“切换全屏”**，即可立即获得沉浸式桌面屏保体验。

### 2. 导入 Wallpaper Engine (小红车)
- 打开 Wallpaper Engine；
- 从本目录的 [index.html](index.html) 导入网页工程，保持 `bg.png`、`wallpaper.js` 与 `project.json` 位于同一目录；
- 宿主属性提供花瓣数量、风速和星尘强度；特效主色通过网页控制面板中的选色器或 RGB 数值框调整，`schemecolor` 不参与画面特效配色。

### 3. 导入 Lively Wallpaper
- 打开 Lively Wallpaper；
- 将本目录下的 [index.html](index.html) 添加为网页壁纸，保留同目录资源。

生成工程需要工具包中的 Python、Pillow 和内置超分工具；打开已生成网页不需要重新运行 Python。浏览器或壁纸宿主的全屏、录制及本地存储兼容性需在实际环境中确认。
