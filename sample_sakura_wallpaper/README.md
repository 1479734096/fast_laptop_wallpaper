# 木之本樱 & 可鲁贝洛斯 4K (16:10) 交互式动态壁纸

本目录为专为 [sakura_16_10_restored_natural.png](file:///D:/diy/pic/05_Image_Restoration_4K/sakura_16_10_restored_natural.png)（3840×2400 原生 16:10 4K 极清底图）量身打造的高清交互式 Web 动态壁纸工程包。

---

## 核心特性

1. **原生 4K 16:10 极清画质**：
   - 采用消除人造生硬描边的最新自然赛璐珞超分底图 `bg.png`，在 4K 屏幕上 100% 点对点呈现手绘墨线与宝石般璀璨的绿瞳。
2. **多层樱花与 3D 翻转动力学**：
   - 远景、中景、前景（景深虚化）樱花花瓣自然飘飞，伴随正弦微风摆动与 3D 自旋翻转，与画面原有的樱花雨完美融为一体。
3. **环境配色星尘闪烁系统**：
   - 四角星芒与柔光浮尘缓缓向上升腾，呼吸明灭；花瓣、星尘和背景柔光共享从底图提取的环境主色，深色背景降低柔光叠加强度。
4. **生动点击互动**：
   - 鼠标点击或手机触摸屏幕任意位置，即可在点击处激发生动的樱花花瓣与魔法星光爆发展开！
5. **2.5D 镜头呼吸与空间视差**：
   - 镜头随正弦波自然呼吸起伏，光影柔和变化；随鼠标移动或手机陀螺仪倾斜呈现多图层深度视差。
6. **动态控制面板与一键录制**：
   - 右上角齿轮可呼出调节面板（花瓣数、风速、星尘强度、视差灵敏度、全屏切换），并支持内置 6 秒 60fps 循环视频一键录制导出。
7. **自动配色与手动覆盖**：
   - 在生成工程时分析底图，外圈四分之一区域权重为中央的三倍，优先参考周围环境；低饱和背景使用淡蓝色。这是颜色统计，不进行人物分割或场景识别。
   - 面板新增一个“特效主色”选择器，立即联动花瓣、常规及点击星尘和柔光；“恢复自动配色”移除手动覆盖，使用 HTML 内保存的自动颜色。
   - 手动颜色按网页路径保存在当前浏览器或壁纸宿主中；相同路径重新生成后继续保留，恢复自动配色即可启用新的取色结果。换路径或换宿主后不保证继承；存储不可用时提示“仅本次生效”，选色仍可使用。
   - 替换 `bg.png` 后，网页不会自行重新取色。在工具包根目录执行 `python pipeline.py --refresh-theme 工程目录`，再重新打开网页。该命令只更新 HTML 的配色数据，不运行超分、不改底图；旧网页缺少配色块时，需要先升级模板。

## 使用与安装指南

### 1. 浏览器直接体验
- 直接双击打开本目录下的 [index.html](file:///D:/diy/pic/06_Sakura_Web_Wallpaper/index.html)；
- 按 `F11` 或点击控制台中的 **“切换全屏”**，即可立即获得沉浸式桌面屏保体验。

### 2. 导入 Wallpaper Engine (小红车)
- 打开 Wallpaper Engine；
- 点击左下角 **“壁纸编辑器”** -> **“打开或新建壁纸”**；
- 点击右下角 **“从文件打开”**，选中本目录下的 [index.html](file:///D:/diy/pic/06_Sakura_Web_Wallpaper/index.html) 或直接将整个 `06_Sakura_Web_Wallpaper` 文件夹放入 Wallpaper Engine 的 `projects/defaultprojects/` 目录下；
- 软件将自动读取 `project.json`，在桌面右侧属性栏即可自由拖动滑块实时调节花瓣数量与风力！

### 3. 导入 Lively Wallpaper (开源壁纸神器)
- 打开 Lively Wallpaper；
- 直接将本目录下的 [index.html](file:///D:/diy/pic/06_Sakura_Web_Wallpaper/index.html) 拖入 Lively 窗口中，点击保存即可。
